# Zona Racing

Aplicación Next.js para la gestión de un taller de motocicletas: reparaciones, ventas rápidas, inventario, compras, clientes y reportes.

## Desarrollo local

Requiere Node.js 20.9 o una versión posterior.

1. Instala las dependencias con `npm install`.
2. Inicia el servidor con `npm run dev`.
3. Abre `http://localhost:3000`.

Para comprobar la compilación de producción, ejecuta `npm run build` y después `npm run start`.
